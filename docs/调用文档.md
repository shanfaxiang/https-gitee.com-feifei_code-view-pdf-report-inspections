# 报告浏览系统调用文档

> 适用对象：临床科室、第三方系统对接工程师
> 用途：通过 URL 直接访问或嵌入（iframe / 新窗口）报告浏览页面，查看检验（LIS）与检查（PACS）报告 PDF。

---

## 一、系统简介

报告浏览系统用于在线查看患者的检验报告与检查报告。系统根据就诊号（`register_id`）与报告编号（`report_no`）从数据库中查询报告，并在网页上展示 PDF 内容：

- 左侧：按日期分组的报告列表（可折叠、可搜索）
- 右侧：报告 PDF 内容（支持全屏查看）

---

## 二、访问地址

| 环境 | 访问地址 |
|---|---|
| 开发环境 | `http://localhost:5080?report_type=lis&register_id=2528525918814720&report_no=117246` |
| 测试环境 | `http://<测试服务器IP>:5081/` |
| 生产环境 | `http://10.0.0.2:9999/pdfviewerweb/?report_type=lis&register_id=2528525918814720&report_no=117246`（以实际数据为准） |

---

## 三、调用方式

- 协议：HTTP **GET**
- 路径：`/` 或 `/Home/Index`
- 方式：浏览器直接访问、`<iframe>` 嵌入、或 `window.open` 新窗口打开均可

---

## 四、参数说明

| 参数名 | 是否必填 | 类型 | 说明 | 示例 |
|---|---|---|---|---|
| `register_id` | **必填** | 数字（就诊号） | 患者的就诊号，对应数据库 `register_id` 字段 | `2528525918814720` |
| `report_type` | **必填** | 文本 | 报告类型：`pacs` = 检查报告（PACS），`lis` = 检验报告（LIS）；仅接受 `pacs` 或 `lis` | `lis` |
| `report_no` | 非必填 | 文本 | 报告编号；**不传**时展示该就诊号下全部有效报告；传入时精确展示该编号报告 | `117246` |

> 说明：`register_id` 在数据库中为 bigint 类型，请以纯数字传入；`report_no` 为文本类型；`report_type` 为必填参数（取值 `lis` / `pacs`），缺失或取值非法时页面会返回错误提示。

---

## 五、调用示例

### 5.1 检验报告（LIS）

展示某就诊号下**全部**检验报告（不传 `report_no`）：

```
http://<服务器>:<端口>/?register_id=2528525918814720&report_type=lis
```

展示**指定编号**的检验报告：

```
http://<服务器>:<端口>/?register_id=2528525918814720&report_no=117246&report_type=lis
```

### 5.2 检查报告（PACS）

展示某就诊号下**全部**检查报告：

```
http://<服务器>:<端口>/?register_id=2528525918814720&report_type=pacs
```

展示**指定编号**的检查报告：

```
http://<服务器>:<端口>/?register_id=2528525918814720&report_no=117246&report_type=pacs
```

---

## 六、页面说明

1. **左侧报告列表**：按日期分组展示，组名格式为 `YYYY-MM-DD`；点击日期组可折叠/展开，报告条目缩进显示；报告名称为「报告标题-报告编号」；顶部支持按报告号/标题搜索过滤。
2. **右侧报告内容**：展示所选报告的 PDF，工具栏提供「全屏」按钮。
3. **报告范围**：未传 `report_no` 时，仅展示有效报告（状态为 1 或 3）。

---

## 七、注意事项

1. `register_id`、`report_type` 为必填参数，缺失时页面会提示错误，请务必传入。
2. 参数值中如包含特殊字符，请进行 URL 编码（UTF-8）。
3. 嵌入方式推荐使用 `<iframe>`，需设置合适的宽度与高度，例如：

   ```html
   <iframe src="http://<服务器>:<端口>/?register_id=2528525918814720&report_type=lis"
           width="100%" height="800" frameborder="0"></iframe>
   ```

4. 报告 PDF 由系统从文件服务器实时读取并输出，客户端无需额外安装插件（浏览器内置 PDF 预览即可）。
